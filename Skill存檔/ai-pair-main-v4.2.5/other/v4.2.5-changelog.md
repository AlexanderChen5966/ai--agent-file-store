# AI-Pair v4.2.5 Changelog — Copilot Credit 計費適應

**發布日期：** 2026-06-01  
**前版本：** v4.2.0  
**觸發動機：** GitHub Copilot 自 2026-06-01 改為 AI Credits 計費；GPT-4.1 列入「預計移除」

---

## 變更總覽

### 🔴 緊急修復

- **copilot-reviewer 預設模型**：`gpt-4.1` → `gpt-5.4-mini`
  - GPT-4.1 被 GitHub 列入「預計移除」，需立即替換
  - GPT-5.4-mini 為更新世代（5.4 vs 5），推理精度更佳
  - 每次 review 成本差僅 $0.005（vs gpt-5-mini），可忽略
  - Fallback chain 更新：`gpt-5.4-mini (LOW) → gpt-5-mini (FREE) → SKIP`

### 🟡 中優先

- **Tier 表格加入 Credit 成本欄**（Output Credits/M）
  - FREE: 200 / LOW: 450~500 / STANDARD: 1,400~1,500 / COMPLEX: 1,400+
  - 為 v4.4 Economy/Quality 模式決策提供成本依據
  - 新增 Credit 計費說明注釋

### 🟢 低優先

- **Claude Haiku 4.5 加入 LOW Tier**
  - 100/M 輸入，500/M 輸出，介於 FREE 和 STANDARD 之間
  - v4.2.5 僅列入 Tier 表格，不改預設 developer 模型
  - 留待 v4.4 `--economy` 模式使用
