## 遷移動機

Google 宣布 Gemini CLI 將於 **2026-06-18** 停止為 Google One 及免費帳號提供服務，並統一遷移至 **Antigravity CLI**（指令：`agy`）。

> 公告原文：
> "Gemini CLI will stop serving requests for Google One and unpaid tiers starting June 18th.
> Please migrate to Antigravity CLI before this date to avoid disruption to your workflow."

AI-Pair v4.2 的 gemini-reviewer 完全依賴 `gemini` 指令。若不在截止日前遷移，Level 1 / Level 3 的 Gemini review 將全部失效（`ERR:CLI_MISSING`）。

---

## 新 CLI 規格（實測 agy v1.0.0）

```bash
agy --version
# 1.0.0

agy --help
# Usage of agy:
#   -p / --print    Run a single prompt non-interactively and print the response
#   --print-timeout Timeout for print mode wait (default 5m0s)
#   --sandbox       Run in a sandbox with terminal restrictions enabled
#   --continue / -c Continue the most recent conversation
#   ...
```

### 與 Gemini CLI 的關鍵差異

| 項目 | Gemini CLI（舊） | Antigravity CLI（新） |
|---|---|---|
| 指令名稱 | `gemini` | `agy` |
| 版本確認 | `gemini --version` | `agy --version` |
| 非互動執行 | `-p "..."` | `-p "..."` ✅ 相同 |
| stdin pipe | `cat file \| gemini -p "..."` | `cat file \| agy -p "..."` ✅ 相同 |
| 模型選擇 | `--model gemini-2.5-flash` | ❌ **無此旗標** |
| 安裝提示 | `brew install gemini-cli` | 待確認（官方安裝指引） |

**最大影響：`--model` 旗標消失。**
v4.2 的 Gemini Tier 系統（LITE / STANDARD / PREVIEW）完全依賴 `--model` 切換，此設計在 `agy` 下**無法繼續使用**。

## 變更一：Gemini Tier 系統廢止

### 現狀（v4.2）

```
Level 1: gemini-3.1-flash-lite-preview（--quick）
Level 2: 不使用 Gemini
Level 3: gemini-3-flash-preview（--deep）
Fallback: gemini-3-flash-preview → gemini-2.5-flash → gemini-3.1-flash-lite-preview → SKIP
```

### v4.3：統一使用 agy（無模型選擇）

由於 `agy` 不支援 `--model`，模型由 Antigravity CLI 內部決定，使用者無法干預。

```
Level 1: agy（--quick）
Level 2: 不使用 agy
Level 3: agy（--deep）
Fallback: agy → SKIP（只有一層）
```

**Tier 表格更新：**

舊 Gemini Tier 表格（移除）：

| Tier | Model | 適用情境 |
|---|---|---|
| **LITE** | gemini-3.1-flash-lite-preview | Level 1 快速掃描 |
| **STANDARD** | gemini-2.5-flash | Level 2 標準 review |
| **PREVIEW** | gemini-3-flash-preview | Level 3 深度 review |

新 agy 記述方式：

```
agy — 模型由 Antigravity CLI 內部決定，無法手動指定
適用：Level 1（--quick）和 Level 3（--deep）
```

## 變更二：CLI 指令更新

### 舊指令（v4.2）

```bash
cat $REVIEW_FILE | gemini --model gemini-2.5-flash \
  -p "Review this code for spec compliance..." 2>&1

# Level 1 fallback
cat $REVIEW_FILE | gemini --model gemini-2.5-flash \
  -p "..." 2>&1
```

### 新指令（v4.3）

```bash
cat $REVIEW_FILE | agy \
  -p "Review this code for spec compliance, missing scenarios, requirement gaps, edge cases.
      Output ONLY in this exact format, each item on its own newline, no extra text:
      SRC:agy
      C|{file:line_or_NA}|{issue}|{fix}
      W|{file:line_or_NA}|{issue}|{fix}
      S|{file:line_or_NA}|{suggestion}|{fix}
      VERDICT:PASS or VERDICT:WARN or VERDICT:BLOCK" 2>&1
```

**注意：**
- `SRC:` 欄位從 `SRC:gemini-2.5-flash` 改為 `SRC:agy`
- 移除所有 `--model` 旗標
- 移除 model-level fallback（不再有 `gemini-2.5-flash` 後備）

## 變更三：錯誤處理精簡

### 舊錯誤處理（v4.2）

```
Exit code 1 + "ModelNotFoundError" → ERR:MODEL, try gemini-2.5-flash
Exit code 1 + "quota" / "429"      → ERR:QUOTA
Exit code 1 + "401"                → ERR:AUTH
Timeout                            → ERR:TIMEOUT, retry once
"command not found"                → ERR:CLI_MISSING
```

### 新錯誤處理（v4.3）

```
Exit code 1 + "quota" / "429"      → ERR:QUOTA
Exit code 1 + "401" / "Unauthorized" → ERR:AUTH
Timeout（無輸出）                   → ERR:TIMEOUT, retry once
"command not found: agy"            → ERR:CLI_MISSING
```

**移除：** `ERR:MODEL`（`--model` 不存在，不會有 ModelNotFoundError）

**Fallback chain 更新：**

```
# 舊（v4.2）
Gemini L3: gemini-3-flash-preview → gemini-2.5-flash → gemini-3.1-flash-lite-preview → SKIP
Gemini L1: gemini-3.1-flash-lite-preview → gemini-2.5-flash → SKIP

# 新（v4.3）
agy（任何 Level）: agy → SKIP
```

### Phase 1 — 驗證 agy 行為（先不改 SKILL.md）

```bash
# 基本 stdin pipe 測試
echo "test code: int x = null_pointer->value;" | agy \
  -p "Review. Output ONLY: SRC:agy / C|NA|null deref|add null check / VERDICT:BLOCK" 2>&1

# 確認壓縮輸出格式符合 Inter-Agent Protocol v1
echo "clean code" | agy \
  -p "Review. Output ONLY: SRC:agy / VERDICT:PASS" 2>&1

# 確認 /tmp 路徑 pipe 正常
REVIEW_FILE=$(mktemp /tmp/review-XXXXXX.txt)
echo "sample diff content" > "$REVIEW_FILE"
cat "$REVIEW_FILE" | agy -p "Reply OK if you received the content" 2>&1
rm -f "$REVIEW_FILE"
```

- ✅ stdin pipe 輸入正常接收

## 備注：角色名稱保留

雖然底層 CLI 從 `gemini` 換成 `agy`，**Agent 角色名稱 `gemini-reviewer` 不需要更改**。

理由：
- 角色名稱代表「負責 spec compliance / missing scenarios 的審查者視角」，與底層 CLI 無關
- 修改角色名稱會影響 `reviewer_set` 快取鍵值（`{copilot,claude,gemini}`），造成既有快取失效
- Team Lead Translation Layer 的輸出標題（`### Gemini Review`）維持現狀，使用者易於識別
