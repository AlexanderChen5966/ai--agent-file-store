## 二、Copilot CLI 實測結果（v1.0.65）

### 關鍵發現：MAI-Code 的正確 slug

| 嘗試名稱 | 結果 |
|---|---|
| `mai-code-1-flash` | ❌ `Model "mai-code-1-flash" from --model flag is not available.` |
| `MAI-Code-1-Flash` | ❌ `not available`（大小寫敏感） |
| **`mai-code-1-flash-picker`** | ✅ **可用，正常回應** |

> **結論：** Copilot CLI 的正確 model slug 為 **`mai-code-1-flash-picker`**（必須帶 `-picker` 後綴、全小寫）。
> 對應 OpenCode（v4.4）格式為 `github-copilot/mai-code-1-flash-picker`，前綴一致。

### Copilot CLI 指令範例

```bash
copilot --model mai-code-1-flash-picker -p "Implement the following task..." 2>&1
```

> **注意：** Copilot CLI（v1.0.65）無 `model list` / `models` 子指令，無法直接列出可用模型；
> 唯一確認方式為逐一 `--model` 試打（會消耗 Credit）。Pro 方案完整清單建議以 VS Code model picker 或官方文件為準。

## 三、MAI-Code-1-Flash vs GPT-5.4 mini 評測比較

> 來源：第三方評測（Bind AI / Microsoft AI / Lushbinary），**非本專案 Phase 2 實測**。

| 維度 | GPT-5.4 mini | MAI-Code-1-Flash | 勝方 |
|---|---|---|---|
| HumanEval | ~88% | ~85.8% | GPT-5.4 mini 略勝（差 ~2%）|
| SWE-Bench Pro（真實任務）| 基準 | 比 Claude Haiku 4.5 高 16 分 | MAI |
| Token 效率（SWE-Bench Verified）| 基準 | 省最多 60% token | **MAI 大勝** |
| 多步推理 / 長上下文 / 多檔重構 | 較弱 | 較穩 | MAI |
| 結構化輸出 / JSON / function calling | 穩定可靠 | 可靠（agentic 導向）| 平手 |
| 成本（Credits/M）| 75 / 450 | 75 / 450 | 同價，但 MAI 省 token = 實質更便宜 |

**結論：**
- **簡單題（HumanEval）**：gpt-5.4-mini 略好，差距可忽略
- **真實多檔 coding / agentic / 省成本**：MAI-Code-1-Flash 評測更優，且 token 效率明顯領先
- developer 場景（真實多檔任務）偏向 MAI；但**納入主力前需經 Phase 2 實測驗證**

## 四、v4.3.5 核心變更

### 變更 A：MAI-Code-1-Flash 加入 LOW Tier 候選（🟡 中）

**現狀（v4.3）：** LOW tier = `gpt-5.4-mini`, `claude-haiku-4.5`

**v4.3.5：** LOW tier 候選新增 `mai-code-1-flash-picker`（與 gpt-5.4-mini 同價、程式碼專用）

> **Phase 2 實測後定案（2026-06-25）：** LOW developer 預設**維持 `gpt-5.4-mini`**；
> `mai-code-1-flash-picker` 僅列入 LOW fallback chain 末段，**不作預設主力**。
> 詳見 `phase2-mai-vs-gpt54mini/README-執行與評分.md`。

**更新後 Tier 表格：**

| Tier | Output Credits/M | Models | 用途 |
|---|---|---|---|
| **FREE** | 200 | `gpt-5-mini` | Fallback，額度耗盡 |
| **LOW** | 450~500 | `gpt-5.4-mini`、`mai-code-1-flash-picker`、`claude-haiku-4.5` | Level 1 掃描、省成本任務、程式碼專用 |
| **STANDARD** | 1,400~1,500 | `claude-sonnet-4.6`、`claude-sonnet-4.5`、`gpt-5.4`、`gpt-5.3-codex` | 預設 Level 2/3 |
| **COMPLEX** | 1,400+ | `gpt-5.3-codex`（複雜推理）| 保留，未來高風險模組 |

### 變更 B：Pro 可用模型清單擴增（🟢 低）

STANDARD tier 補入 v4.2.5 後新增的 Pro 可用模型：`gpt-5.4`、`claude-sonnet-4.5`。
Gemini 3.1 Pro / 3.5 Flash 雖 Copilot Pro 可用，但 Gemini 系列 review 由 agy（v4.3）負責，**不從 Copilot CLI 走**，故僅列入成本表參考，不納入 Copilot Tier。

### 變更 C：MAI-Code Phase 2 實測（🟢 低）— ✅ 已完成

以車號驗證工具（3 檔多檔任務）實測，相同 prompt 只換模型：

| 指標 | `gpt-5.4-mini` | `mai-code-1-flash-picker` |
|---|---|---|
| 品質加權總分（/34）| **34** | 26 |
| output token | **8.7k** | 13.0k（多 49%）|
| AI Credits | **5.28** | 13.5（2.56×）|
| 耗時 | **70s** | 127s |
| 約束遵守 | ✅ 自包含測試 | ❌ 違規 import 第三方 `package:test` + 捏造 shim |
| 測試真實性 | ✅ 逐案 PASS | ❌ 空殼、`dart run` 零輸出、摘要謊報通過 |

**結論：兩項切換條件（正確性不退步、token 省 ≥15%）皆不成立 → 維持 `gpt-5.4-mini`。**
第三方評測宣稱的「省 60% token」在本專案真實多檔場景未重現。

> **附帶發現（需後續處理）：** 實測過程確認 `cat $FILE | copilot -p`（stdin pipe）在 CLI v1.0.65 **失效**，任務內容須改用 `-p` 直傳。此影響 `cli-invocation-ref.md` / `agents-prompts.md` 既有指令，建議併入本版或獨立 hotfix 修正。
