# 如何使用四大框架體系生成 Claude Skills

## 框架體系概覽

我們提供**四個互補的參考框架**,構成完整的 AI 能力構建體系:

### 四大框架

```
┌────────────────────────────────────────────────────────┐
│                 完整框架體系                            │
├────────────────────────────────────────────────────────┤
│                                                        │
│  1. SCQA_Framework_Reference.md                        │
│     情境-衝突-問題-答案 (溝通表達框架)                  │
│     用途: 清晰表達、決策呈現、階段性總結                │
│                                                        │
│  2. TBRC_Framework_Reference.md                        │
│     論點-邊界-路徑-總結 (內容組織框架)                  │
│     用途: 知識結構化、文檔組織、SOP 設計                │
│                                                        │
│  3. MAPS_Methodology_Reference.md                      │
│     心智-架構-提示-系統 (系統化方法論)                  │
│     用途: 整體設計、團隊協作、能力建設                  │
│                                                        │
│  4. 5A_Plus_Enhanced_Reference.md                      │
│     AIM→ACQUIRE→ATTEMPT→ADJUST→APPLY→PLUS (實踐循環)  │
│     用途: 項目執行、迭代優化、持續運營                  │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 框架之間的關係

```
                  ┌─────────────────┐
                  │   MAPS (總指導)  │
                  │  M × A × P × S  │
                  └────────┬────────┘
                           │
            ┌──────────────┼──────────────┐
            │              │              │
    ┌───────▼───────┐ ┌───▼────┐ ┌──────▼──────┐
    │     SCQA      │ │  TBRC  │ │     5A+     │
    │   溝通表達     │ │ 內容組織│ │  實踐循環   │
    └───────┬───────┘ └───┬────┘ └──────┬──────┘
            │              │              │
            └──────────────┴──────────────┘
                      │
              ┌───────▼────────┐
              │  Claude Skills  │
              │  完整解決方案   │
              └────────────────┘
```

**使用順序建議**:
1. **MAPS** 提供總體思維框架和方向指導
2. **5A+** 提供具體的執行步驟和循環
3. **SCQA** 幫助在每個階段清晰表達
4. **TBRC** 組織最終的文檔和知識

## 完整範例: 創建"學習筆記整理" Skill

```

- 當前做法: 手動整理,每次 2-3 小時
- 頻率: 每週 5 次
- 痛點: 筆記雜亂、不知道哪些是核心、難以回顧

請用資產化價值評估框架:
1. 計算資產化價值分數

## 進階使用技巧

### 技巧 1: 框架不是死板的步驟

```
❌ 錯誤想法:
"我必須嚴格按照框架的每一步執行"

✅ 正確理解:
"框架是工具箱,根據需要選擇合適的工具"

示例:
- 簡單 Skill: 只用 5A+-A1→A3 + 簡化的 TBRC
- 複雜項目: 用完整的四框架
- 緊急任務: 直接 A3 (MVP),回頭補 A1-A2
```

---

### 技巧 2: 框架可以往復循環

```
5A+ 不是線性的:

正常流程:
A1 → A2 → A3 → A4 → A5 → Plus

實際使用:
A1 → A2 → A3 → [發現問題] → 回到 A2 補充學習
         → A3 → A4 → [需要重大調整] → 回到 A1 重新評估
                  → A5 → [試點失敗] → 回到 A4 優化

框架是指南,不是枷鎖
```

---

### 技巧 3: 框架之間可以穿插使用

```
不要想著"先用完 MAPS,再用 TBRC,最後用 SCQA"

而是:
- 每個 5A+ 階段都可以用 SCQA 表達
- 每個 MAPS 維度都可以用 TBRC 組織
- 每份文檔都可以用 SCQA 開頭 + TBRC 展開

框架是工具,靈活組合使用
```

---

### 技巧 4: 根據受眾調整表達

```
同一個 Skill,不同受眾,不同表達:

向管理層匯報:
- 用 SCQA (簡潔有力)
- 重點: ROI、風險、決策

向團隊分享:
- 用 TBRC (系統完整)
- 重點: 方法論、實踐路徑

向新手說明:
- 用簡化的 5A+ (快速上手)
- 重點: 快速開始、範例

框架幫你適應不同受眾
```

  □ A: 答案具體,可執行

□ **TBRC 內容組織**
  □ T: 論點清晰,有驗證
  □ B: 邊界明確,有說明
  □ R: 路徑分層,可操作
  □ C: 總結收攏,有行動

□ **MAPS 系統性**
  □ M: 資產化思維明確
  □ A: 架構設計合理
  □ P: Prompt 清晰有效
  □ S: 有系統化落地路徑
```

## 最佳實踐總結

### 核心原則

1. **框架是工具,不是枷鎖**
   - 根據需要靈活使用
   - 可以簡化,可以組合
   - 重在解決問題

2. **從小處著手,逐步完善**
   - 第一次: 只用 5A+-A1→A3
   - 熟悉後: 加入 SCQA/TBRC
   - 大項目: 使用完整框架

3. **框架之間互補使用**
   - MAPS 提供思維
   - 5A+ 提供步驟
   - SCQA 提供表達
   - TBRC 提供組織

4. **數據驅動,持續迭代**
   - 不追求一次完美
   - 基於反饋優化
   - 保持靈活調整
